# BoaMe

BoaMe is a single-page, smooth-scrolling React + TypeScript website built with Vite. It showcases the BoaMe plastic-recovery and rewards ecosystem with clear sections for the problem, solution, how it works, inclusive access, impact, team, and FAQs.

## Tech Stack
- React 19 + TypeScript
- Vite 8
- Tailwind CSS v4
- Framer Motion
- Lucide React
- React Router (for hash routing fallback)

## Local Development
```bash
npm install
npm run dev
```

## Build & Preview
```bash
npm run build
npm run preview
```

## Linting
```bash
npm run lint
```

## Features
- Single-page app with smooth scroll navigation and scroll-spy
- Mobile drawer with accessible focus states
- Responsive layout (320px+)
- Optimized images and lightweight production build

## Notes
- This repo contains source assets in `src/assets` and optimized public images in `public/images`.
- Contact CTAs are present in the UI as placeholders pending a contact destination. No secrets are committed.
